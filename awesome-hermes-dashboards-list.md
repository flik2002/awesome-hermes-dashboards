## 🔄 Next Curation Pass

Future passes should verify:

*   whether each repo is active and publicly reachable;
*   whether it has screenshots or a runnable UI;
*   which Hermes APIs it can integrate with (`/api/sessions`, `/api/mcp`, Gateway, cron, tools, memory, logs);
*   license compatibility;
*   whether the project is Hermes-native, forkable, or only UX inspiration.
